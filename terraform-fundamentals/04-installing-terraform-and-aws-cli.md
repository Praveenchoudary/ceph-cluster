# Installing Terraform & AWS CLI

## Install Terraform

Follow the official HashiCorp installation guide:

https://developer.hashicorp.com/terraform/install#linux

---

## Install AWS CLI

Follow the official AWS CLI installation guide:

https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html

---

## Verify the Installation

Check Terraform:
```bash
terraform version
```

Check AWS CLI:
```bash
aws --version
```

---

## Next Step

Once both are installed and verified, move on to [AWS Account Setup & Authentication](./05-aws-account-setup-and-authentication.md) to configure credentials so Terraform can create resources in your AWS account.
