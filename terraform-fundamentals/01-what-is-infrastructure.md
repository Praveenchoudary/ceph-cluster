# What is Infrastructure?

Infrastructure is everything required to run an application.

In simple words, **Infrastructure is the foundation of an application.** Without infrastructure, an application cannot run.

---

## Example

Suppose you develop an Online Shopping Application. The application needs:

- A **server** to run the application
- A **database** to store customer details
- **Storage** to save images and files
- A **network** so users can access it
- **Security** to protect the application

All these together are called **Infrastructure**.

## What is a Server?

A **Server** is a computer that runs applications and provides services to users.

### Example

**Your laptop:**
- Used by one person
- Runs personal applications

**Server:**
- Used by many users
- Runs business applications
- Usually runs 24×7

One server can serve hundreds or even thousands of users.

---

## What is a Data Center?

A **Data Center** is a building where many servers are kept. It also contains:

- Network switches
- Routers
- Backup power
- Cooling systems
- Internet connection

---

## What is Cloud Computing?

**Cloud Computing** means renting infrastructure instead of buying it. Instead of purchasing servers, companies rent them from cloud providers.

Popular cloud providers:
- AWS
- Microsoft Azure
- Google Cloud Platform (GCP)

### Traditional vs Cloud

| Traditional | Cloud |
|---|---|
| Buy servers | Rent servers |
| High cost | Pay only for what you use |
| Takes days or weeks | Ready in minutes |
| Manage hardware yourself | Cloud provider manages hardware |

## Real-World Example

Imagine your company has 100 applications. Each application needs:

- 2 Servers
- 1 Database
- 1 Network
- 1 Storage
- Security

Creating all of this manually takes time. This is why companies use cloud platforms like AWS.

## Summary

- Infrastructure is everything required to run an application.
- A Server is a computer that runs applications.
- A Data Center is a building that contains many servers.
- Cloud Computing allows you to rent infrastructure.
- AWS provides cloud services such as EC2, VPC, S3, and RDS.
