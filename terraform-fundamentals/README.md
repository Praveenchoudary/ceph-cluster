## Suggested Order

Read these in order if you're new to Terraform:

```
Infrastructure → IaC → Terraform → Install Tools → AWS Auth Setup → (start writing .tf code)
```

Once you've completed all 5 topics here, you're ready to move on to writing your first EC2 resource, variables, state, backends, and modules — covered in the other project folders in this repo.
